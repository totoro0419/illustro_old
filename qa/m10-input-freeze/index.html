指の入力がどこで止まるか調べる版

PR #49のキャンバス操作・仮線・表示処理を維持したまま、画面上で実際に止まった時間を記録します。今回は指を数える仕組みやキャンバス操作を作り直していません。

診断付きIllustroを開く

  1. 太いGペンで長い線を描いてペンを離します。
  2. 「線を作品に反映しました」が出る前に指を置き、右上の診断表示を確認します。
  3. 「時計の最大停止」「画面更新の最大間隔」「入力遅延」に注目してください。
  4. 右上の診断表示を、指を置く前後と確定後にスクリーンショットで残してください。

数字が変わらなくても、確定後には過去の入力遅延や処理停止時間が表示されます。停止したかどうかを確認するための版です。

この調査版は、キャンバスの挙動を変えずに入力と表示の時間を測定します。物理端末のGPU占有とイベントが発生する前のOS側の事情は、この記録だけでは完全には識別できません。
