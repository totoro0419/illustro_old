仮線から本線の間に、何が止まるのか

Illustroの修正版を動かしたまま、実際に指の入力が届いた時刻、画面の処理停止、正式反映までの動きを記録します。追加の別画面ではありません。

入力の記録付きIllustroを開く

  1. 大きな作品で太いGペンの長い線を描いて離します。
  2. 本線になる前に指を1本または2本置き、移動・拡大・回転を試します。
  3. 本線が反映された後、右上の「診断結果をコピー」を押します。
  4. コピーした記録をこの会話に貼ってください。数字が途中で止まっても、後から停止時間を調べられます。

時計が長時間停止した場合はブラウザーの画面処理側、時計が動き続けているのに入力通知が来ない場合はタッチの配送や判定側を優先調査します。どちらも今回の実機では未確認です。
